# Project Construct

![Project Construct](assets/project-construct-wordmark.svg)

Project Construct is a math-first companion to [Project Viz](https://yiuhong.github.io/demo-library/). This public repository will hold the library. Work is just beginning.

The mark above is the light lockup, [`assets/project-construct-wordmark.svg`](assets/project-construct-wordmark.svg). Yiu Hong Ko is a psychology and cognitive neuroscience researcher in Hong Kong and a registered social worker (RSW).

A workbench draft lives on the workbench draft pull request. Lessons are Python files under `library/`, run in the page with a pinned Pyodide build. The draft is static files in that branch. GitHub Pages is not enabled.
