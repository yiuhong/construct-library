A hands-on library for mathematical and computational psychology and neuroscience.

Lessons start with the basic mathematics and move on to their applications in computational modelling. Each one opens as a Jupyter notebook you can run in the browser — write in a cell, press Shift+Enter, and see printed output and plots under the cell that produced them.
