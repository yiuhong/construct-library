Cite

Cite the library as a whole when a syllabus, a paper, or a slide refers to the collection. The version identifies this release.

APA 7

Ko, Y. H. (2026). Project Construct: A hands-on library for mathematical and computational psychology and neuroscience (Version 0.1.0). https://yiuhong.github.io/construct-library/

The title is in APA sentence case.

BibTeX

@misc{ko2026projectconstruct,
  author  = {Ko, Yiu Hong},
  title   = {{Project Construct: A hands-on library for mathematical and computational psychology and neuroscience}},
  year    = {2026},
  version = {0.1.0},
  url     = {https://yiuhong.github.io/construct-library/},
  note    = {Version 0.1.0, last updated 17 November 2026}

Citing one lesson

Keep the library citation above when you mean the whole collection. For one lesson, name that lesson, then the library, the version, and the lesson URL. Titles come from the library page.

Jupyter Notebook basics. Project Construct: A hands-on library for mathematical and computational psychology and neuroscience (Version 0.1.0). https://yiuhong.github.io/construct-library/notebook.html?path=getting-started/01-jupyter-basics.ipynb

This example is Jupyter Notebook basics, in Getting started.

Reuse

What you may do

  • Assign the URL of the library, or of one lesson, in a course, a syllabus, or a learning platform.
  • Fork the repository, adapt a lesson for your own students, and host that copy.
  • Put a screenshot or a still of a notebook on a slide or a handout, and keep the credit line with it.

Limits

  • Do not present a copy as the official Project Construct, and do not imply that Yiu Hong Ko endorses it.
  • Do not remove the attribution. Keep the author’s name, a link to the source, and the CC BY 4.0 notice. If you changed the material, start the credit line with “Adapted from”.
  • Do not add legal terms or technical locks that stop the next person from reusing the material under the same license.

Embedding a lesson page

A lesson lives at notebook.html: the library title bar, then a Jupyter notebook that runs in the browser. You can put that URL in a frame. It is still a whole notebook. The frame needs to be tall, and the visitor’s browser downloads the Python runtime before a cell can run. For a course, assigning the lesson URL is the reliable way to reuse it. A screenshot or a still, with the credit line, is the straightforward way to show a lesson on a slide.

If a frame is still what you need, this one points at Jupyter Notebook basics. Change the path in the URL for another lesson, and keep a title that names the lesson. The frame shows the notebook page, not a cropped figure.

<iframe src="https://yiuhong.github.io/construct-library/notebook.html?path=getting-started/01-jupyter-basics.ipynb" title="Jupyter Notebook basics" width="100%" height="720" style="border:0"></iframe>

Accessibility

The aim is usable keyboard access and text that can be read. That is a goal for these pages, not a finished audit, and this site does not claim a conformance level. If a control cannot be reached from the keyboard, or text is hard to read, report it on GitHub Issues and name the page.

Report a mistake

Report a bug or a teaching error on GitHub Issues. Name the lesson or the page and what you expected to see. The source is on GitHub.

About

Project Construct: A hands-on library for mathematical and computational psychology and neuroscience. Lessons start with the basic mathematics and move on to their applications in computational modelling. Each one opens as a Jupyter notebook you can run in the browser — write in a cell, press Shift+Enter, and see printed output and plots under the cell that produced them.
