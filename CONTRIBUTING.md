# Contributing

Thank you for helping Project Construct.

## Bugs and ideas

Report a bug, a teaching error, or an idea on [GitHub Issues](https://github.com/yiuhong/project-construct/issues). Name the lesson or the page, what you expected, and what happened. For an idea, start the title with "Idea:".

## Pull requests

Pull requests are welcome. Opening a pull request is not a guarantee of merge.

Small corrections — a wrong label, a broken link, a clearer sentence — are the easiest to review. Keep teaching text, explanations, and figures under CC BY 4.0, and the HTML, CSS, JavaScript, and Python that run the site and the notebooks under MIT, as [LICENSE](LICENSE) and [LICENSE-CODE](LICENSE-CODE) describe. [license.html](license.html) lists that split.

How to run the site locally is in the [README](README.md).

## Version

When a change is something a syllabus should record, set the new version and date in [`js/site-meta.js`](js/site-meta.js). Repeat that version and date in the footer on `index.html`, `notebook.html`, `cite.html`, and `license.html`, and in the citation text on `cite.html`. Set the same version and `date-released` in [`CITATION.cff`](CITATION.cff), and add an entry to [CHANGELOG.md](CHANGELOG.md).
